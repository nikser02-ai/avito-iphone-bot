# Бот мониторинга iPhone на Авито

Следит за свежими объявлениями об iPhone в Москве и Московской области,
сравнивает цену с медианой по такой же модели и памяти и присылает в личку
только то, что заметно дешевле рынка и не выглядит разводом.

## Главное, что нужно знать до запуска

У Авито **нет публичного API для поиска чужих объявлений** — официальный API
предназначен для продавцов. Поэтому бот ходит в мобильный API, а тот закрыт
антиботом: **с нероссийского IP приходит 403 сразу**, без вариантов.

Проверить своё окружение:

```bash
.venv/bin/python -m avitobot.main --doctor
```

Команда покажет внешний IP, страну и результат тестового запроса. С текущей
машины она возвращает `403` — исходящий адрес в Нидерландах. Рабочие варианты:
резидентный российский прокси в `PROXY` или запуск с VPS в России.

## Как это устроено

Просто «самое дешёвое» бесполезно: в топе всегда чехлы, аппараты на запчасти
и приманки. Поэтому объявление проходит четыре ступени.

1. **Разбор** (`normalize.py`) — из заголовка достаются модель, память и
   состояние АКБ, из всего текста — красные флаги: запчасти, реплика, привязка
   к iCloud, предоплата, аксессуар вместо телефона, услуга ремонта.
2. **Ценовой индекс** (`storage.py`) — медиана по связке *модель + память*
   за последние три недели, только по чистым объявлениям, с обрезкой хвостов.
   Пока по связке меньше `MIN_SAMPLE` объявлений, медиане не верим и молчим.
3. **Оценка** (`scoring.py`) — скидка к медиане плюс признаки добросовестности
   (АКБ, рейтинг продавца, число фото, длина описания) дают оценку 0–100.
   Цена ниже `SCAM_FLOOR` от медианы трактуется как приманка: такое приходит
   отдельной карточкой с предупреждением, а не как находка.
4. **Отправка** (`bot.py`) — карточка с фото, ценой, разницей к медиане и
   ссылкой. Дедупликация по объявлению и пользователю.

Полное описание объявления стоит отдельного запроса, поэтому конвейер работает
в два захода: по заголовку отсеивается очевидный мусор и наполняется индекс,
а полный текст запрашивается только для тех, кто уже прошёл по цене. На тестовой
выдаче из 18 объявлений это 4 запроса вместо 18.

## Установка

```bash
cd /Users/macbookpro/avito_iphone_bot
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
cp .env.example .env    # впишите BOT_TOKEN от @BotFather
```

Запуск:

```bash
.venv/bin/python -m avitobot.main
```

## Команды бота

| Команда | Что делает |
|---|---|
| `/start` | включить подписку |
| `/settings` | показать текущие фильтры |
| `/budget 20000-90000` | диапазон цены |
| `/models iPhone 13, iPhone 14 Pro` | следить только за этими моделями |
| `/battery 85` | минимальное состояние АКБ, `0` отключает |
| `/discount 20` | минимальная скидка к медиане, % |
| `/last` | последние находки |
| `/stats` | медианы, которые бот вывел из наблюдений |
| `/stop`, `/resume` | пауза и возобновление |

## Тесты

Работают офлайн, доступ к Авито не нужен:

```bash
.venv/bin/python tests/test_normalize.py
```
```bash
.venv/bin/python tests/test_pipeline.py
```

Первый — 38 проверок разбора на реальных формулировках, включая ловушки
(«отдам за 15 000 руб» не должно превращать iPhone 13 в iPhone 15; «128 гб»
не должно опознаваться как iPhone 12). Второй прогоняет весь конвейер на
подставной выдаче: находка уходит, приманка с предоплатой и телефон с привязкой
к iCloud отсеиваются, чехол и запчасти не проходят.

## Когда что-то сломается

Авито меняет формат ответа без предупреждения. Весь сетевой код и разбор полей
собраны в `avito.py`, извлечение устойчиво к перестановке ключей. Если выдача
перестала разбираться:

```bash
.venv/bin/python -m avitobot.main --sweep
```

Сырые ответы лягут в `dumps/` — по ним правится функция `extract_item`.

## Настройки

Всё в `.env`, важное:

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `PRICE_MIN` / `PRICE_MAX` | 10000 / 150000 | бюджет, рубли |
| `MIN_DISCOUNT` | 0.15 | насколько ниже медианы должно быть объявление |
| `SCAM_FLOOR` | 0.45 | ниже этой доли от медианы — приманка |
| `MIN_SAMPLE` | 8 | сколько объявлений нужно, чтобы поверить медиане |
| `MIN_BATTERY` | 85 | минимальное состояние АКБ |
| `POLL_INTERVAL` | 180 | пауза между проходами, секунды |
| `REQUESTS_PER_MINUTE` | 20 | потолок темпа запросов |
| `PROXY` | пусто | российский прокси |

## Правовая сторона

Парсинг противоречит пользовательскому соглашению Авито. Для личного
мониторинга это распространённая практика, но риск блокировки IP или аккаунта
лежит на владельце бота. Темп запросов намеренно занижен.

## Запуск на BotHost

Хостинг запускает `python bot.py` по `Procfile` — файл уже в корне, проект
остаётся чистым Python, чтобы не сбить определение типа сборки.

Загрузите папку, пропишите в переменных окружения `BOT_TOKEN` и `ADMIN_ID`
и отправьте боту `/doctor`. Отчёт ответит сразу на оба вопроса, которые решают,
подходит ли хостинг:

- **Пролезает ли IP.** Если в отчёте `RU` и «выдача получена» — всё, платить
  за VPS не нужно. Если `403` — адрес хостинга в чёрном списке Авито, и здесь
  ничего не поправить: нужен прокси в `PROXY` либо другая площадка.
- **Переживает ли база перезапуск.** Перезапустите бота и снова отправьте
  `/doctor`. Если база опять «создана 0 мин назад» — файлы стираются при
  рестарте, ценовой индекс не накопится и находок не будет никогда.
  Лечится только внешним хранилищем базы.

Учтите, что IP у такого хостинга общий на много ботов: его могли сжечь чужие
парсеры ещё до вас, и по той же причине он может перестать работать в любой
момент не по вашей вине.

## Интерфейс

Постоянная клавиатура: «🔍 Что ищем», «⚙️ Фильтры», «💾 Сохранённые»,
«📊 Рынок», «⏸ Пауза».

**«Что ищем»** — переключатели категорий (iPhone, Apple Watch) и выбор
конкретных моделей списком с постраничной навигацией. Если ни одна модель
не отмечена, бот следит за всеми в выбранной категории.

**Под каждой находкой** три кнопки:

- **✉️ Написать продавцу** — открывает объявление на Авито
- **💾 Сохранить** — откладывает в «Сохранённые», кнопка меняется на «✅ Сохранено»
- **⏭ Пропустить** — убирает карточку из переписки

Карточка показывает цену, медиану рынка, размер выгоды в процентах и рублях,
состояние АКБ, рейтинг продавца, район и число фото.

## Apple Watch

Вторая категория разбирается так же, как iPhone, только вместо объёма памяти
вариантом служит размер корпуса: Ultra 3/2/1, Series 4–11, SE/SE 2/SE 3,
корпуса 38–49 мм. Медиана считается отдельно по каждой паре модель+размер.

Отдельная сложность — ремешки: их продают тысячами, и в заголовке они выглядят
почти как часы. Отличаются позицией слова: у аксессуара оно стоит перед
названием («Ремешок для Apple Watch»), у самих часов — после
(«Apple Watch Series 9, два ремешка в комплекте»). Это же правило спасает
телефоны от отсева по «чехол в подарок».
